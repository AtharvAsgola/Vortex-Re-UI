# Vortex-Re-UI
**Vortex with a better, revamped UI.**

# Steps to Install
1. Click on Releases
2. On the latest release (the highest release), click on "Source Code (zip)" to download the Source Code and then unzip it
3. After unzipping, if theres another folder with the same name inside the unzipped folder, use that folder instead.
4. For chromium browsers: Go to (yourbrowsername)://extensions and then enable Developer mode, and then press "Load unpacked" and select the folder.
5. The extension will be ready.

# Steps to Update
Do the same steps as the steps to install, and it will be updated.
